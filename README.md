# EPICBOX — Cloud Storage Platform

EPICBOX is a modern cloud-storage web application for securely uploading, organising, and managing files from one place.

**Live application:** [epicbox.vercel.app](https://epicbox.vercel.app/)

## Highlights

- User authentication and account management
- File upload and cloud storage workflows
- File-type filtering and organised browsing
- Responsive dashboard built for desktop and mobile
- Supabase-backed data and authentication services
- Optional object storage integrations for scalable file handling

## Technology

- React and TypeScript
- Vite
- Tailwind CSS
- Supabase
- AWS S3 SDK
- React Router
- Zod and React Hook Form

## Project structure

- src/App.tsx — application entry and top-level UI
- src/pages — route-level screens
- src/components — reusable interface components
- src/context — shared application state
- src/services — data and storage integrations
- src/db — database-related configuration
- src/types — shared TypeScript types
- public — static assets

## Getting started

### Prerequisites

- Node.js 20 or newer
- npm 10 or newer
- Supabase project credentials for connected features

### Install dependencies

    npm install

### Configure environment variables

Create a local .env file using .env.example as a reference. Add only the public client configuration required by the frontend. Never commit private keys, service-role keys, or other secrets.

### Start the development server

    npm run dev

Vite will print the local URL in the terminal.

### Create a production build

    npm run build

### Preview the production build

    npm run preview
